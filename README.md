# pandas_ml
Домашнее задание 1 по машинному обучению по теме pandas
## О задании
Задание состоит из двух разделов, посвященных работе с табличными данными с помощью библиотеки pandas и визуализации с помощью matplotlib. В первом разделе я выполнила базовые задания с помощью вышеуказанных библиотек, а во втором распределила студентов по курсам.

## Технологический стек
- Python
- Pandas: Фильтрация и агрегация данных.
- Matplotlib: Построение гистограмм и графиков.

## Результаты
В ходе выполнения задания были освоены методы эффективной работы с DataFrame, исключающие итерации по строкам, что значительно ускоряет обработку данных в Python.
